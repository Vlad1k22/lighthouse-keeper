# Интерьеры острова

| Место | Как попасть | Что внутри |
| --- | --- | --- |
| Хижина смотрителя | **E** у двери с крыльца | Койка для отдыха и дежурства, чугунная печь для рыбы, домашнее радио |
| Радиостанция | **E** у двери справа от наружного пульта | Передатчик, индикатор питания, аккумулятор после ремонта |
| Катер «Северный» | По трапу на палубу, затем **E** у двери рубки на левом борту | Каюта с койкой, проход через переборку, штурвал для отплытия |
| Старый склад | Пешком через открытые ворота | Стеллажи, металлолом, стол с инструментами, аптечка |

В закрытых помещениях ромб **◇** отмечает выход, а **◆** — доступное оборудование. **F9** и **F10** сохраняют и восстанавливают положение внутри. При отплытии с внутреннего штурвала герой возвращается на палубу движущегося катера.

Камера от третьего лица приближается и открывает ближние стены. На складе она также скрывает кровлю и ближайшие деревья со стороны камеры. Стены, мебель и стеллажи имеют коллизии.
