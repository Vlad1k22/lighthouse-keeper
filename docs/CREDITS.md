# Материалы и источники

## Собственные учебные материалы

Концепция проекта предложена командой: Влад Людкевич, Костя Котельников, Андрей Виговский и Артём Артамонов. В репозитории сохранены презентация PowerPoint, текст выступления в Word, исходники первого прототипа и его скриншот.

Портреты участников и концепт острова подготовлены с помощью генерации изображений по материалам команды. В `assets/portraits/Стиль_портретов.txt` сохранено описание общего художественного стиля. Для четвёртого портрета сохранены первоначальный и более мультяшный варианты.

## Референсы

Изображения в `docs/references/` — скриншоты сторонних игр, используемые как учебные визуальные ориентиры. Они не являются игровыми ассетами «Смотрителя маяка». Исходные адреса изображений сохранены в `steam-screenshots.json`.

- [Project Zomboid](https://store.steampowered.com/app/108600/Project_Zomboid/) — вид сверху, читаемость окружения и бытовые механики выживания; разработчик The Indie Stone.
- [Darkwood](https://store.steampowered.com/app/274520/Darkwood/) — тревожная атмосфера и опасность ночи; разработчик Acid Wizard Studio.
- [DREDGE](https://store.steampowered.com/app/1562430/DREDGE/) — морская тема, рыбалка и сочетание спокойной рутины с хоррором; разработчик Black Salt Games.

Внешние изображения принадлежат их правообладателям. Презентация также содержит ссылки на источники в заметках слайдов.

## Движок

Для демоверсии «Первая смена» модели острова, зданий, персонажа и предметов сформированы из собственных треугольных мешей и примитивов Godot. Прибой, шаги и звук взаимодействия синтезируются кодом. Шейдер воды, анимация ходьбы и частицы дыма находятся в исходниках проекта. Скриншоты first-shift-*.png получены при реальном запуске демоверсии в Godot.

[Godot Engine](https://godotengine.org/) распространяется по лицензии MIT. Официальная информация о лицензии: https://godotengine.org/license/.

В обновлении окружения модели растений, чаек, снастей, радио и инструментов также собраны из собственной геометрии. Шейдеры прибоя, ветра и экранной атмосферы написаны для проекта; дождь, ночной фон и радиотреск синтезируются локально без сторонних аудиозаписей.

Мини-игра рыбалки вдохновлена механикой удержания рыбы в управляемой зоне из Stardew Valley. Логика, оформление интерфейса и условные изображения рыб подготовлены для этого проекта; сторонние игровые изображения и звуки для рыбалки не использованы.

Цветокоррекция мира для хоррор-оформления реализована в screen_atmosphere.gdshader: приглушение цвета, холодные тени, сохранение тёплых источников света, виньетка и процедурное зерно. Внешние текстуры или фильтры для этого не используются.

Для переработки окружения natural_geometry.gd создаёт ветви, хвойные побеги, листья, траву и деформированные камни. pine_needles.gdshader формирует силуэт хвои и ветер, weathered_surface.gdshader — фактуру материалов. Геометрия и материалы разработаны кодом для проекта, сторонние ассеты и фотографии не используются.
